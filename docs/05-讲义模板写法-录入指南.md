# MathAPP 知识库与习题库内容维护说明

课程内容存储在数据库中，有两种维护方式：成批的课程内容写成文件放在 `content/library/`，用导入命令写入数据库（见第 6 节）；零星修改可以直接在 Django 后台（`/admin/`）进行。前端只读取已发布的目录和正文；新增或修改内容不需要改前端文件。

## 1. 内容结构

知识库和习题库是**两棵独立的树**。课程可按内容粒度使用三级或四级结构：

```text
知识库
└─ 微积分（课程）
   └─ 第一章 极限与连续（章）
      └─ 数列极限（节，填写正文）

习题库
└─ 微积分（课程）
   └─ 第一章 极限与连续（章）
      └─ 基础训练（节，填写题目正文）
```

| 层级 | 节点类型 | 是否填写正文 |
| --- | --- | --- |
| 课程 | 目录节点（📁） | 否 |
| 章 | 目录节点（📁） | 否 |
| 节 | 内容节点（📄），或用于细分的目录节点（📁） | 直接作为内容时填写正文 |
| 小节（可选） | 内容节点（📄） | 是 |

- 课程和章只能是目录节点；节可以直接承载正文，或作为目录节点再细分为小节。
- 小节必须是内容节点且不能有下级；后台会阻止第五层和不符合层级的节点类型。
- 任意节点下线后，它及其全部下级不会在前台显示，但数据不会删除。

### 重要字段

- **内容归属**：只在课程根节点选择“知识库”或“习题库”。
- **课程代码**：只在课程根节点填写。同一门课程在两棵树使用相同代码，例如 `calculus`；前台链接和最近学习依赖它，通常不要修改。
- **标识（slug）**：全站唯一。小节标识关联已读、收藏、错题和学习进度，发布后不要随意修改。
- **副标题、适合人群、简介**：只在课程根节点填写，用于前台课程卡片。
- **访问权限**：只对小节生效。选择“会员”后，后端会阻止非会员读取正文。

## 2. 在后台维护

打开 `http://127.0.0.1:8000/admin/`，在“课程内容”中进入“内容树”。页面顶部可切换：

- **知识库树**：维护讲义、定义、定理、例题和解析。
- **习题库树**：维护题组、练习题和解析。

### 新建课程

1. 在对应内容树点击“新建课程”。
2. 上级节点留空，节点类型选“目录节点”。
3. 填课程名称、唯一标识、课程代码和内容归属。
4. 填副标题、适合人群和简介后保存。
5. 在课程下新建章，章下新建“内容节点”作为节并填写正文。
6. 只有需要更细分时，才将节建为目录节点，再在其下新建内容节点（小节）。

同一门课程可在两棵树各建一份，名称和课程代码相同即可，但内容归属不同。

### 日常操作

- **新增下级**：课程下建章；章下直接建内容节，或先建节目录再建小节。
- **编辑**：修改名称、排序、权限或正文。
- **排序**：在同一父节点下拖动到上/下边缘调整顺序。
- **移动**：只能在三级/四级结构及节点类型允许的范围内移动。
- **上下线**：控制该节点和所有下级的前台可见性。

> 0008 迁移曾给章下直挂的正文套一层“未分类”节，0009 迁移已自动拆除，正文直接挂回章下，不需要手工处理。

## 3. 前台行为

- 知识库页只读取知识库树，习题库页只读取习题库树。
- 侧边栏显示“章 → 节”；使用四级结构时才额外显示小节分组。
- 两个库都可使用同一课程链接，如 `?course=calculus`。
- 正文按需加载；课程打开时不会下载全部小节正文。
- 会员小节前后端都会校验权限。

## 4. 正文模板指令

正文写在“节（内容节点）”或“小节（内容节点）”中，支持 Markdown 和 LaTeX：

```text
@chapter 编号 | 章标题
@section 编号 | 节标题
@subsection 编号 | 小节标题（仅四级内容需要时使用）

@text 标题
普通正文，支持 Markdown 和 LaTeX。

@def 编号 | 标题
@theorem 编号 | 标题
@corollary 编号 | 标题
@proposition 编号 | 标题
@lemma 编号 | 标题
@property 编号 | 标题

@problem 例题 1 | 计算题 | 基础 | 数列极限,同阶无穷大 | 入门例题
题目块依次为：标题、题型、难度、知识点、标签。

@solution 解析
紧跟定义、定理、命题或题目后，生成可折叠解析/证明。

@image 标题 | 图片地址 | 图注 | alt | 宽度
宽度可写 wide、medium、small。

@tikz 标题 | 图注 | 宽度
\begin{tikzpicture}
  \draw (0,0) circle (2cm);
\end{tikzpicture}

@table 标题 | 说明
| 列 1 | 列 2 |
| --- | --- |
| A | B |

@code 标题 | js | 说明
console.log('hello')

@interactive-sine 标题 | 说明

@interactive function | 标题 | 说明
```

### TikZ 图形

修改含 `@tikz` 的小节后，在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe manage.py render_tikz
```

该命令将 SVG 编译结果写入数据库；未编译时前台会提示尚未渲染。环境安装和支持宏包见 `scripts/tikz/README.md`。当前渲染器不支持中文标注。

### 小插图（@aside）

`@image` / `@tikz` 是独占一整行的大图模块；`@aside` 是嵌在题面、解析、证明或 `@text` 正文右侧的小示意图。用了 `@aside` 的字段改为左右两栏：左栏文字，右栏插图，两栏顶端对齐，中间有留白和一条淡分隔线，文字和图不会重叠。适合重积分的积分区域、曲线围成的平面区域这类“边读解答边对照”的图。

```text
@aside 类型 | 标题 | 图注 | 尺寸 | 图片地址
配置行（key: value，每行一条）
```

- 写在哪个字段里，图就出现在那个字段的右栏（题面、`@solution` 之后的解析、定理正文等）；它不会结束当前字段，后面的文字仍属于同一段解析。同一字段写多个 `@aside` 时在右栏上下排列。
- 配置行必须紧跟在 `@aside` 指令之后；遇到第一行不是 `key: value` 的内容（或空行）配置就结束，之后是正文。
- 类型：`image`（图片）、`plane`（平面图，SVG，悬停显示坐标，首次出现时区域淡入、曲线描出）、`space`（空间图，可拖动旋转，默认缓慢自转）。
- 尺寸决定右栏宽度：`s` 约占 1/5（164～200px），`m` 约占 1/4（196～250px，默认），`l` 约占 1/3（230～300px）。平面区域图用 `s` 就够清楚；空间图建议用 `m` 或 `l`，太窄时刻度会挤。
- 公式自动折行：左栏里的行间公式如果是 `A = B = C = …` 这样的长等式链，渲染时自动在顶层等号处断行并按等号对齐（相当于改写成 `aligned`），短的相邻片段合并在同一行。已经手工写了 `\begin{aligned}` 或 `\\` 的公式原样保留。只有一个等号的超长公式不会被拆，左栏内横向滚动，这类公式建议手工分行。
- 正文区域窄于 560px（手机）时改为上下排列：图在上居中，文字在下。
- 图右上角有放大按钮，打开大图查看（空间图在大图里同样能旋转）。某一行配置写错时，图下方会用红字提示是哪一行，其他行照常绘制。

表达式按教材写法：`x^2+y^2`、`sqrt(1-x^2)`、`2x`、`4cos(t)`、`2pi`、`e^(-x)`；可用 `sin cos tan asin acos atan sinh cosh exp ln log sqrt abs min max` 以及常数 `pi`、`e`。

区域（`fill:` 和曲面定义域通用）：

| 写法 | 含义 |
| --- | --- |
| `rect a b c d` | 矩形 |
| `disk R` / `disk R cx cy` | 圆盘 |
| `ring R1 R2` | 圆环 |
| `x a b, y g1(x) g2(x)` | X 型区域 |
| `y c d, x h1(y) h2(y)` | Y 型区域 |
| `t a b, r r1(t) r2(t)` | 极坐标区域（`t` 也可写 `θ`） |

平面图（`plane`）配置：

| 配置 | 写法 |
| --- | --- |
| `fill:` | `区域 ; opacity 0.2 ; color #hex ; label D ; border off` |
| `curve:` | `y = f(x)`、`x = g(y)`、`r = f(t)`，可加 `; x a b` 限定范围，选项 `label 文字`、`at 0.35`（标注位置 0～1）、`dashed`、`color` |
| `param:` | `x(t), y(t) ; t a b` 参数曲线 |
| `point:` | `x, y, 标注` |
| `box:` | `x0 x1, y0 y1`，不写时自动取景（自动包含原点、横纵等比例） |
| `ticks:` / `axes:` / `grid:` | `off` / `off` / `on` |

空间图（`space`）配置：

| 配置 | 写法 |
| --- | --- |
| `surface:` | `z = f(x,y) ; 定义域`（也可 `x = f(y,z)`、`y = f(x,z)`，定义域变量相应换成 y z / x z），选项 `opacity 0.5`、`color #hex`、`mesh off`、`grid 30` |
| `param:` | `x(u,v), y(u,v), z(u,v) ; u a b ; v c d` 参数曲面（柱面、球面、锥面） |
| `curve:` | `x(t), y(t), z(t) ; t a b` 空间曲线（交线、边界），选项 `color`、`width`、`dashed` |
| `point:` | `x, y, z, 标注` |
| `view:` | `方位角 仰角`，默认 `35 24` |
| `spin:` | `off` 关闭自转 |
| `box:` / `ticks:` / `axes:` / `labels:` / `height:` | 坐标范围 / 刻度 / 坐标盒 / 轴名 / 高宽比 |

配色统一取自站点色系，平面图和空间图一致：区域和曲面用主色墨绿；不指定 `color` 时曲面按高度着色，从深墨绿过渡到浅沙色；曲线默认深墨绿，需要强调的交线、边界用 `color warm`（暖棕）；刻度统一为灰色等宽小字，轴名统一为斜体衬线。`color` 可写的名字有 `accent`（墨绿）、`warm`（暖棕）、`sand`（浅沙）、`ink`（墨色）、`blue`、`red`、`gray`，都是调和过的低饱和色，也可以写 `#hex`，但建议优先用名字保持全站统一。

```text
@problem 例题 4 | 计算题 | 基础 | 三重积分 |
利用柱面坐标计算 $\iiint_{\Omega}z\,\mathrm{d}v$，其中 $\Omega$ 由 $z=x^2+y^2$ 与 $z=4$ 围成。

@solution 解
@aside space | 积分区域 Ω | 旋转抛物面与平面 z=4 所围
surface: z = x^2 + y^2 ; disk 2
surface: z = 4 ; disk 2 ; opacity 0.5 ; color sand
curve: 2cos(t), 2sin(t), 4 ; t 0 2pi ; color warm
$\Omega$ 在 $xOy$ 面上的投影为 $\rho\leqslant2$……

@problem 例题 3 | 计算题 | 基础 | 二重积分 |
计算 $\iint_D xy\,\mathrm{d}\sigma$，$D$ 由 $y^2=x$ 与 $y=x-2$ 围成。

@solution 解
@aside plane | 积分区域 D | 按 Y 型区域分层 | s
fill: y -1 2, x y^2 y+2 ; label D
curve: x = y^2 ; label x=y^2

抛物线与直线交于……

@text 说明
@aside image | 示意 | 图注 | s | /media/figures/example.png

```

写作建议：`@aside` 放在字段开头即可，位置不影响版式。

## 6. 用文件维护课程

成批的课程内容以文件形式保存在 `content/library/`，一节一个文件，文件即内容的“源头”，用导入命令同步到数据库。

### 目录与命名

```text
content/library/
├─ knowledge/                         讲义（知识库，当前的主要内容）
├─ exercise/                          习题（习题库），课程文件夹已预设，暂无内容
├─ overview/                          速览（考前快速复习），课程文件夹已预设，暂无内容
│                                     三个库下的课程文件夹同名，都用课程代码
└─ knowledge/calculus/                以讲义库的微积分为例
      ├─ course.json                  课程名称、副标题、适合人群、简介、slug 前缀、排序
      ├─ 01-函数与极限/                两位章号-章名
      │  ├─ 01-映射与函数.math.md      两位节号-节名.math.md
      │  └─ 02-数列的极限.math.md
      └─ 14-重积分/
         └─ 06-二重积分计算专题.math.md
```

- 课程之间的顺序取 course.json 的 `order`（数字小的在前，按本科学习顺序以 10 为间隔编号，便于插入新课）。
- 章、节的顺序取文件夹和文件名前面的两位编号，名称取编号后面的部分；调整顺序或改名只需改文件名。
- 章的标识自动生成为 `<slug前缀>-ch<章号>`，例如 `calculus-ch14`。
- 每个节文件开头写 front matter，`slug` 是这一节的永久标识，关联已读、收藏和学习进度，写定后不要修改；改章节名、调顺序都不影响它。

```text
---
slug: calculus-14-6
access: member
---
@chapter 14 | 重积分
@section 14.6 | 二重积分计算专题
……正文指令……
```

`access` 可省略：新建的节默认免费，已有的节保持后台的设置；填 `free` 或 `member` 时以文件为准。

### 导入

双击项目根目录的 `导入课程内容.bat`，或运行：

```powershell
.\.venv\Scripts\python.exe manage.py import_library                  # 导入 content/library 下全部课程
.\.venv\Scripts\python.exe manage.py import_library --dry-run        # 只检查，不写数据库
.\.venv\Scripts\python.exe manage.py import_library content/library/knowledge/calculus
```

- 命令按 slug 新增或更新节点，可重复执行，没有变化的节点不会被改动。
- 文件里已删除的章节在数据库中改为下线，不会真正删除，已读和收藏记录保留；文件恢复后再导入即重新上线。
- 如果某节在后台修改的时间晚于文件的修改时间，导入时会跳过这一节并给出提示，以免覆盖后台的修改；确认以文件为准时加 `--force`。
- 导入只改数据库，前端不需要重新构建；刷新页面即可看到新内容。

### 增删改查

| 操作 | 做法 |
| --- | --- |
| 查 | 在 `content/library/<库>/<课程>/` 下按章节文件夹查找，或全文搜索 `.math.md` |
| 改 | 编辑对应 `.math.md` 文件后导入 |
| 增 | 在章文件夹里新建 `NN-节名.math.md`（写好 slug），或新建 `NN-章名/` 文件夹后导入 |
| 删 | 删除文件或文件夹后导入，对应节点自动下线 |
| 调序、改名 | 修改文件名前的编号或名称后导入，slug 不变，用户记录不受影响 |

长期以文件为准时，后台只用来临时修正；临时修正后记得把同样的改动写回文件，否则下次 `--force` 导入会被覆盖。

### 让内容 AI 直接改文件（renew_work）

在 `.math.md` 里写一段 `renew_work: 要求……`（到空行或下一条 `@` 指令为止），再把文件路径和 `docs/RENEW_GUIDE.md` 交给内容 AI，它会直接修改文件并删掉标记。改完双击项目根目录的 `更新内容.bat`，一次完成导入和 TikZ 渲染。导入时残留的标记会被自动去掉，不会显示到网站上，并在命令行里提示。

### 从讲义稿件批量生成

`scripts/manuscript_to_library/` 保存了把微积分 Markdown 稿件转换成上述文件的工具和补写的解答，用法见该目录的 `README.md`。其他课程的稿件可以照此转换。
