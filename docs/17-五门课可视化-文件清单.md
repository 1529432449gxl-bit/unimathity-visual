# 五门课可视化文件清单

本表由仓库现状自动整理，覆盖概率统计、复变函数、实变函数、常微分方程、抽象代数五门课。交互页面放在 `frontend\public\interactive\`，讲义在 `content\library\knowledge\<课程代码>\`，选题依据为 `review\<课程>-可交互建议-gpt.md`（筛选后版本）。

整理时核对过：五门课的交互页面全部被讲义引用，没有孤立页面；讲义中没有指向不存在页面的链接；五份清单登记的页面文件全部存在。
