# 宣传视频文件清单

宣传片工程由“Unimesity 炫酷宣传视频”会话制作，用 Remotion 4（React + TypeScript）写成，整片由独立模块按时间线拼接，配乐由脚本合成。本文整理它的文件位置与现状，复用方法以工程内的 `promo-video/AGENTS.md` 为准。

## 在哪里

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 工程代码 | 本仓库 `claude/promo-video` 分支的 `promo-video/` 目录 | 尚未合入 main；分支只新增这个目录，不涉及讲义和交互页面 |
| 60 秒成片 | 制作会话容器内 `promo-video/out/unimathity-promo.mp4` | 不进仓库（`out/` 已忽略），需从该会话下载，或本地 `npm run render` 重新渲染 |
| 配乐 | `promo-video/public/music.wav` | 不进仓库，本地 `npm run music` 可重新生成（62 秒，约 -14 LUFS） |
| 截图检查 | 会话容器内 `promo-video/out/qa/` | 不进仓库 |

本地使用建议放在 `D:\MathAPP\promo-video\`（或任意目录），与网站代码互不影响：

```powershell
git fetch origin claude/promo-video
git checkout origin/claude/promo-video -- promo-video
cd promo-video
npm install
npm run studio
```

## 还缺什么

- 照片：`public/photos/` 为空，痛点段的照片位全是占位框。按槽位名放入 `pain-01`～`pain-09`、`quote-01`（jpg/png）即可，不用改代码。
- 学生原话：PainQuote 的默认原话与署名是示意文案，需换成真实采访。
- 成片与配乐只在制作会话的容器里，会话回收后会消失，请尽快下载，或在本地重新渲染。
