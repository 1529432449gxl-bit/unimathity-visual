# 线性代数可视化选题提示词

> 建立：2026-11-05，由微积分版改写，融入线性代数讲义的写作规矩与可视化规矩。
> 用途：按 11 号分工方案，由 GPT 通读线性代数讲义，提出可交互、可视化模块的建议清单。站长与 Claude 筛选后由 Claude 制作。
> 用法：整段复制下面的提示词交给 GPT，提示词已包含全部要求，单独使用即可。

```text
任务：通读 Unimathity 网站线性代数课程的全部讲义，在知识、技巧、概念处找出适合做成可交互或可视化模块的位置，写成一份建议清单。例题和习题本轮不管。全程中文。

一、文件位置
1. 讲义：D:\MathAPP\content\library\knowledge\linear-algebra\，共 10 章（多项式、行列式、线性方程组、矩阵基础、矩阵的相抵与相似、二次型与矩阵的相合、线性空间、线性变换、λ-矩阵、欧氏空间），每章若干 .math.md 文件。
2. 制作要求表：D:\MathAPP\docs\08-可视化形式与内容-制作要求表.xlsx。第一页按"内容类别 × 呈现形式"写了要点和禁忌，第二页是通用规格。先读这张表，所有建议都按表里的类别和形式来写。
3. 目录正在调整：第五、六章的部分内容可能已经移动（二次型相关内容统一收在第六章）。以你读到的文件为准，位置写文件路径加小节标题，方便我们在编号变动后仍能找到。

二、工作范围
1. 只看知识类的指令块：@def、@theorem、@proposition、@property、@corollary、@lemma、@text 以及讲解性文字。
2. @problem 与 @solution（例题和解答）一律跳过。
3. 讲义里已经有 @interactive 的位置，在清单里单独列出，不重复建议。
4. 全程只读，不修改任何讲义文件，不写 renew_work 标记。

三、选题标准
只在满足以下至少一条的地方提出建议：
1. 学生常见的理解难点，靠文字和公式不容易想明白，例如行列式是体积的伸缩倍数、矩阵乘法是变换的复合、秩是像空间的维数、特征向量是只被伸缩的方向、直和与和的区别、正交投影、若尔当块的方幂。
2. 内容本身是一个"过程"，动起来比静态图更清楚，例如消元法逐列消零、施密特正交化逐个扣除投影、配方法逐步化二次型为平方和、打洞原理把分块矩阵的一块消成零、λ-矩阵化史密斯标准形。
3. 有可调的参数，调一调就能看出规律，例如矩阵元素变化时网格的变形、行列式由正变负时的翻转、二次型系数变化时等值线在椭圆与双曲线之间的切换、对称矩阵正交替换时主轴的旋转。
4. 空间图形，学生难以想象，例如三维空间中的子空间、交与和、正交补、镜面反射与旋转。

课程有四条贯穿全课的主线：消元法（初等变换）、秩的等式与不等式、打洞原理、矩阵分解。主线上的知识点优先考虑，并尽量让同一条主线在不同章节的模块用同一套画面语言，例如消元法在行列式、线性方程组、矩阵求逆、相抵标准形、相合标准形、λ-矩阵中都用同一种逐步消零的动画。建议中注明它属于哪条主线。

坚持少而精：每章挑 2 到 4 处最值得做的，宁缺毋滥。纯计算技巧、定义的形式化表述、一看就懂的性质，都不要建议。第一章多项式与几何关系不大，可以只提 0 到 2 处。

四、画面规矩（硬性）
1. 矩阵、行列式、分块矩阵、消元过程类的演示，一律画 n 阶一般情形：用带省略号的一般矩阵示意，例如左上角、右下角与省略号，或分块示意；不用具体的二阶、三阶、四阶数值矩阵代替一般情形。
2. 几何直观类画面可以在平面或空间里示意，但不标具体矩阵和数值，画面表达的是一般规律。
3. 画面上不放说明文字和数值读数，确有必要的标注用英文，越少越好。
4. 只展示方法正常工作的情形，不展示退化、失败或不稳定的情形。
5. 只能手动点击前进后退的逐步演示，一律带自动播放（播放与暂停）。
6. 我们认可的水准：首页六格动画、数值分析 5.2 消元演示、8.1 特征值几何意义演示。画面设想向这几个看齐：干净、动态、一眼看懂。

五、每条建议的格式
1. 位置：文件路径 + 小节标题 + 所在的块（例如"03-线性方程组/01-高斯消元法.math.md，3.1.2 增广矩阵与消元步骤，@theorem 3.2"）。
2. 知识点：一句话。
3. 学生痛点：这里难在哪，一两句话。
4. 所属主线：消元法、秩的等式与不等式、打洞原理、矩阵分解之一，不属于则写"无"。
5. 内容类别：从制作要求表第一列选一个。
6. 呈现形式：从静态图片、小插图、自动播放动画、可交互模块、逐步演示中选一个。
7. 画面设想：画面上有什么、怎么动、学生能操作什么，两三句话，必须符合第四部分的画面规矩。
8. 优先级：高、中、低。"高"留给学生最常卡住、做出来提升最明显的地方。

六、交付
把清单写成一个文件：D:\MathAPP\review\线性代数-可交互建议-gpt.md。
1. 按章节顺序排列，每章一个二级标题，全文标题不超过两级，不加粗。
2. 文件开头先写一张汇总表：章节、建议数、高优先级数。
3. 汇总表之后单列"主线联动"一节：每条主线列出被建议的位置，并说明统一画面语言的设想，一两句话。
4. 文件末尾单列"已有交互模块"一节，列出讲义中已有 @interactive 的位置，每个附一句评价：保留、建议重做或建议删除。
5. 不提及任何教材或参考书的名字。

工作方式：速度优先，通读一遍即可，不做多轮自我审阅。准确性由我和 Claude 复核。遇到拿不准的地方，按最合理的理解处理，在文件末尾用一两句话说明。
```
